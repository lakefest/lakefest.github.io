# MARS — карта мест Москвы и области

Сайт: https://lakefest.github.io/mars-map/

224 карточки мест, 210 точек с координатами и архив из 411 публикаций публичного канала [Mars](https://t.me/MarsikzbMsK). Снимок от 8 ноября 2026 года.

Карта с линиями метро, поиск по текстам и ближайшим станциям, избранное, маршруты в Яндекс Картах, оригинальные описания и локальные обложки. Посты без координат доступны в списке. Ближайшая станция рассчитана по прямой; маршрут рассчитывают Яндекс Карты.

## Запуск

Сборка не требуется: `python -m http.server 8080 --directory docs`. GitHub Pages публикует папку `mars-map` ветки `main`.

## Обновление данных

Python 3 и Pillow: `python collect.py`, затем `python prepare.py`. Обновления не автоматические. Координаты, описания и состояние мест взяты из публикаций, даты указаны в карточках. Все исходные фото и видео открываются по ссылке на пост.

## Источники

Публикации и фото: @MarsikzbMsK; карта: OpenStreetMap/CARTO; станции метро: api.hh.ru/metro/1. Leaflet 1.9.4 (BSD-2-Clause). Фоновая карта, шрифты и Яндекс Карты требуют интернета. Избранное хранится в браузере.
