# B2/190 — presentation of the two-seat buggy concept

Public page: https://lakefest.github.io/buggy/

Static HTML, CSS and JavaScript; no build step or visitor login. The model uses WebGL 1 with a JPEG fallback. Pointer controls support one-finger rotation and two-finger zoom. PDFs and source files are served from `files/`.

The content presents concept version 0.1; dimensions and material counts are inherited from the project documents. This is not a structural certification or a finished manufacturing design.

The GitHub Actions workflow `buggy-pages.yml` publishes this folder and preserves `lakefest.html` at its original path.
